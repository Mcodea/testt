# Captures du référentiel — contrôles locaux

Captures produites par `tests_web/test_referentiel_codes.py`, avec Chromium,
1366×768, données de référence et espace utilisateur temporaire. Elles montrent
la révision publiée en lecture seule. Le même test les régénère dans les artefacts CI.

Tests automatiques : ouverture clavier, Échap et restitution du focus ; recherche,
pagination et absence de débordement horizontal à 1366×768, 1920×1080, 2560×1440 ;
édition et suppression exclusivement dans le brouillon ; code invalide refusé
avant écriture ; texte saisi échappé dans table, attributs et panneau ; conservation
de la révision publiée. Le pied de table reste visible à 1366×768.

Ces deux écrans n'ont pas de maquette dédiée parmi les trois fichiers fournis.
Ces captures ne remplacent pas les comparaisons à produire pour le tableau de bord
et l'écran Variables. Les polices embarquées et les icônes du cahier restent à intégrer.
