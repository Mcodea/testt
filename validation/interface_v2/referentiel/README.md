# Captures du référentiel V2

Générées dans Chromium par `tests_web/test_referentiel_codes.py` à 1366×768,
avec les seules données du référentiel livré, sur espace temporaire.
Les lignes CT affichées dans les correspondances sont les références historiques
vers FT déjà validées, pas un type proposé pour les nouveaux projets.

Le test couvre les trois objets, le clavier, le focus, les saisies échappées,
l'édition/suppression en brouillon sans publication, l'ambiguïté refusée, le motif
obligatoire, l'archivage réversible et les commandes métier conservées.
Recherche et absence de débordement sont vérifiées à trois tailles d'écran.

Ces captures n'ont pas de maquette dédiée. Elles ne remplacent pas les comparaisons
à réaliser sur les trois maquettes du tableau de bord et des Variables.
