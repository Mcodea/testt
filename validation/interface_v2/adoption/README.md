# Captures de l'adoption contrôlée

Produites par `tests_web/test_adoption.py` dans Chromium à 1366×768, avec deux
équipements EV fictifs, sans données d'exploitation. Les anciens noms contenant
FDC servent uniquement à vérifier la conservation des projets historiques et la
confirmation explicite du passage aux noms physiques V2 validés.

- `adoption-detail-1366.png` : noms par équipement, cases décochées et commandes.
- `adoption-retour-1366.png` : accès à la sauvegarde et à l'annulation après adoption.

Les tests vérifient le téléchargement identique à l'original, les adresses
conservées, l'annulation exacte, l'aperçu périmé refusé, le clavier et trois
résolutions. Il n'existe pas de maquette dédiée à cette fenêtre : ces captures ne
valident pas les trois maquettes Tableau de bord / Variables du cahier.
